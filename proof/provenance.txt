# Honest caveats
The attested binary is the promoted pin (deploy/nimrod/MANIFEST
sha256=9a3cf47e237e5e4f477329c41f0b35692b5058a10b2777bd70377b9e3f2235cf, commit a0da75f), which must be
byte-identical to the live mainnet unit's /proc/<pid>/exe. Re-run
this script with --pin after every promote; proof/check-pin.sh and
proof/verify.sh fail if a pin is present and does not match.
Nim compiles via C. The binary hash is for this toolchain and this
tree. A different Nim, C compiler, libc, or build path is expected
to produce different bytes. Behavioural re-runs (R1 shim, in-repo
R5 tests) are the stronger check. See REPRODUCIBLE-BUILD.md.
This script refreshes provenance + MANIFEST only. Frozen evidence in
r1/ r2/ r4/ r5/ is not regenerated from outside this repository.
